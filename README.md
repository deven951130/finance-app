# 個人理財管理系統

用 Python + Streamlit + SQLite 做的個人理財工具，在自己電腦上執行，資料只存在本機。

## 功能

- **總覽**：每月現金流（收入 − 固定支出 − 負債還款 − 生活預算 = 每月可存）、現金／股票市值／負債餘額，單一個股占總市值超過 40% 時顯示警告。
- **負債**：名稱、剩餘金額、每月還款。按「已還一期」會同時扣剩餘金額和手上現金，並顯示預計還清月份（假設下一期在下個月繳）。
- **持股**：名稱、代號、帳戶、股數、均價、現價（手動輸入）。
  - 同一代號在不同帳戶會合併計算（均價為加權平均）
  - 顯示市值、損益、報酬率、占總市值比例；顏色依台股習慣，紅色是賺、綠色是賠
  - 虧損的個股顯示回本價 = 總成本 ÷ (股數 × (1 − 0.001425 − 0.003))，以及距離現價還要漲幾 %
- **設定**：每月收入、手上現金、緊急預備金、預備金目標（預設 17000）
- **每月預算**：吃飯、約會禮物、交通、其他，各自設定金額
- **記帳**：輸入金額、類別、日期、備註；顯示本月明細、各類別進度條、本月還能花多少
- **固定支出**：例如電話費、iCloud，可新增、刪除

「本月還能花多少」= 四個類別的預算總和 − 本月已記帳的支出總和（超支會變負數）。
固定支出目前只是清單，不會扣進這個數字。

## 專案結構

```
finance-app/
├── app.py            # Streamlit 畫面（各頁面）
├── db.py             # 資料庫讀寫（所有 SQL 都在這裡）
├── models/
│   ├── budget.py     # 本月還能花多少
│   ├── cashflow.py   # 每月現金流
│   ├── debt.py       # 負債：還一期、預計還清月份
│   └── stocks.py     # 持股：合併、市值、損益、回本價
├── tests/            # pytest 測試
├── data/             # 資料庫檔案放這裡（不會進 git）
├── requirements.txt
└── pytest.ini
```

## 安裝

需要 Python 3.10 以上。

```bash
cd finance-app

# 建立虛擬環境（讓這個專案的套件跟系統分開）
python -m venv .venv

# 啟用虛擬環境
# Windows：
.venv\Scripts\activate
# macOS / Linux：
source .venv/bin/activate

# 安裝套件
pip install -r requirements.txt
```

## 執行

```bash
streamlit run app.py
```

瀏覽器會自動打開 http://localhost:8501 。第一次執行時會自動建立 `data/finance.db`。

## 測試

```bash
pytest
```

## 隱私

`data/`、`*.db`、`.env`、匯出的 `*.csv`／`*.xlsx` 都已列在 `.gitignore`，不會被 commit。
上傳 GitHub 前可以用 `git status` 確認沒有出現資料庫檔案。
